# 📊 GCD Calculator

I implemented the Euclidean Algorithm by using the C++ programming language. That small program was developed by using if-else condition, which helps to easily find the Greatest Common Division (GCD) of two numbers.

## ✒️ What is GCD ?

The largest integer that divides two or more integers without leaving a remainder is called the GCD.
